书边译

选中单词，书页上直接出释义；拍一页书，找出里面的生词。

外屏5.38 英寸 约 425 × 623 dp
内屏7.58 英寸 约 860 × 608 dp

点书页上的单词试试，长按或双击是整句翻译

怎么用

  1. 外部词典静读天下、KOReader 等可设为词典，长按单词直接出卡片。
  2. 选中菜单其他 App 选中后点「书边译」，原型演示的就是这种。
  3. 磁贴微信读书这类自带菜单的 App，先复制再点下拉栏磁贴。

外屏和内屏

  • 外屏底部卡片，最高半屏，上半页仍可读。
  • 内屏右下角 380 dp 浮动卡片，不挡左页；可换到左下角并记住。
  • 展开、合上时保留当前卡片。

查词和体积

  • 离线词典 ECDICT，约 6 万常用词，毫秒出结果，不联网不花钱。
  • 变形词自动还原，wharves 查到 wharf，knocking 查到 knock。
  • 整句翻译走在线大模型，配了 Key 才出现。
  • Kotlin + 原生 View，不引入第三方库，APK 主要是词典，估计几 MB。

拍照找生词

  • 拍照或从相册选一页，本机识别文字，按词频先去掉常用词。
  • 剩下的词交给 Jev 判断你是否认识，一次请求约 1 秒。
  • Jev 按上下文从词典义项里选出本句的意思，比如 mole 选「防波堤」。
  • 点「认识」的词以后不再列出。

需要你确认

  1. 平时用哪个阅读 App，决定主入口。
  2. 书是否只有英文。
  3. 整句翻译首版要不要；要的话用 DeepSeek 官方 Key 还是 Magpie 网关。
