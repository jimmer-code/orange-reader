# 书边译

个人用的看书查词 APK，目标设备是小米 18 Fold（HyperOS 4），外屏和内屏都要适配。两种模式：查单词（快速查词、读纸书时拍照找生词）和 ePub 模式（书库 + 阅读器，阅读界面参照 Apple Books）。主要用途是查单词，整句翻译最次要。当前阶段：方案 + 交互原型，还没写 Android 代码。

开发文档：`SPEC.md`（给开发者的完整规格和验收清单）。

原型：`prototype/index.html`（浏览器直接打开，页头可切换外屏、内屏）。旧版只查词的原型在 `prototype/v1-word-only.html`。

## 两种模式

底部（外屏）或侧栏（内屏）三个标签：查单词、书库、生词本。打开 App 默认进查单词，并弹出键盘。

### ePub 模式：书库和阅读器

- 书库：继续阅读、筛选（全部、在读、读完）、封面网格（外屏 3 列，内屏 5 列）。右上角「+」用系统文件选择器导入 ePub，无封面时按书名生成封面。
- 打开书：封面放大过渡到书页，关闭时缩回原位。
- 阅读器：WebView 渲染 ePub 的 XHTML，CSS 分栏分页；页眉显示章节名，页脚显示页码；内屏默认双页，可在设置里关掉。点左侧上一页，点右侧下一页，点中间显示工具栏；也可以左右滑动。
- 主题与设置：原色、安静、纸张、粗体、平静、专注六种主题；字体 Literata、Source Serif、无衬线；字号；翻页方式「仿真 / 滑动 / 淡入 / 无」，系统开启「减少动态效果」时一律不用动画。
- 仿真翻页：原生 View 截取前后页位图，按手指位置做翻折网格和阴影，跟手翻页；原型里用 CSS 3D 翻转示意。
- 目录、书签、进度条；进度按字符位置保存，换字号、展开或折叠后回到同一处。
- 查词：长按单词（或双击）直接出词典卡片，不经过选中菜单。阅读器能拿到所在句子，所以卡片顶部给出「本句中」的意思（Jev choice 题，离线时只显示义项列表）。外屏卡片在底部，单词在页面下半部时改到顶部；内屏卡片浮在另一页上。收藏的词在书里加虚线下划线。

### 查单词

- 搜索框在屏幕中间，高 60dp，输入文字 28sp 衬线体；打开即聚焦。下面是「拍一页」「从相册选」和最近查过的词。
- 开始输入后，搜索框滑到顶部，下方按前缀逐字出结果；回车查第一个结果。清空后回到中间。
- 外屏点结果弹出词典卡片；内屏左边是结果列表，右边显示释义。
- 拍一页、从相册选：见下文「拍照找生词」。

## 外部阅读 App 入口

用别的阅读 App 时也能查词。在阅读 App 里选中单词，点菜单里的「书边译」，书页上浮出词典卡片；关掉卡片就回到书页。

入口，按方便程度排列：

1. 阅读 App 的「词典」设置：实现 ColorDict 协议（`colordict.intent.action.SEARCH`），静读天下、KOReader 等可以把书边译设为外部词典，长按单词直接出卡片，不用再点菜单。
2. 系统文字菜单：`ACTION_PROCESS_TEXT`，所有用系统选中菜单的 App 都能用，选中后多点一下。
3. 快捷设置磁贴：先复制，再点磁贴。用于微信读书这类自带选中菜单的 App。

卡片是透明主题的 Activity，不需要悬浮窗或无障碍权限。

## 查词

- 离线词典：[ECDICT](https://github.com/skywind3000/ECDICT)（MIT 许可），自带音标、中文释义、词性、词频。按词频截取常用的约 6 万词，转成 SQLite 打进 APK，查询在毫秒级，不联网、不花钱。
- 词形还原：用 ECDICT 的 `exchange` 字段和 `lemma.en.txt`，`wharves` 显示为「wharf 的复数」并给出 wharf 的释义，`hypos`、`knocking` 这类变形同理。
- 查不到的词（生僻词、专有名词、古旧用法）提示「词典里没有」，提供一个「问 AI」按钮。
- 朗读用系统 `TextToSpeech`。
- 生词本：卡片上一点收藏；首页按时间列出，可导出 CSV。

已知限制：选中菜单只传入选中的文字，拿不到所在句子，所以卡片按常用度列释义，不能直接给出「本句中的意思」。旧书里的冷僻义（如 spleen 的「郁闷」、mole 的「防波堤」）靠 ECDICT 收录的全部义项覆盖。

## 拍照找生词

拍一页书或从相册选图，只列出可能不认识的词，不翻译全文。

1. 识别文字：本机 OCR。候选是 ML Kit 文字识别的内置模型版本（拉丁文字约增加 4 MB），需要真机确认在没有 Google 服务的国行系统上能用；不行就把图片发给支持视觉的大模型。
2. 粗筛：分词、词形还原，去掉专有名词、词频最高的约 3000 词，以及你点过「认识」的词。
3. 判断难度：剩下的候选词交给 Jev（TypeSafe `jev-latest`，接口 `https://api.typesafe.ai/v1/systemone`）。一次请求，每个候选词一道 noul 题：「这位读者是否需要查这个词才能理解它在本段中的意思」。state 里放读者水平描述和这段原文。概率 ≥ 0.5 列为生词，0.5 以下收进「可能认识」。
4. 语境义：对列出的生词，再发一次请求，每个词一道 choice 题，选项是 ECDICT 里的义项，由 Jev 选出本段中的意思。
5. 结果：图片上高亮生词，旁边列出原形、音标和语境义；点词互相定位，可收藏或标记「认识」。

2026-10-31 实测（jev-1.14.0，《白鲸记》第一章一段，16 个候选词，一次请求 1.1 秒）：hypos 0.81、spleen 0.78、mole 0.77、insular 0.64，grim、wharves、methodically 约 0.53；street 0.05、waves 0.07、funeral 0.12。义项选择：spleen 选「郁闷，忧郁」（0.88），mole 选「防波堤」（1.0）。测试脚本没有放进项目。

Jev 的概率没有按个人校准，界面只用来排序和分组，不显示数字。0.5 的阈值是起点，用「认识」和收藏的记录调整。

Jev Key：ops-hub 里没有登记，实际在 `~/workspace/sandbox/road-scout-mcp/.env` 的 `TYPESAFE_API_KEY`。手机端在设置里填一次，存在应用私有存储，不进 APK 和 Git。需要真机确认手机网络能访问 `api.typesafe.ai`。

## 整句翻译（次要）

选中超过一个词时走在线大模型，接口按 OpenAI Chat Completions 格式写，默认 DeepSeek，地址、模型、Key 可在设置里改。国行 HyperOS 没有 Google 服务，ML Kit 离线翻译不可用。没配 Key 时整句功能不显示，查词照常可用。

## 外屏与内屏

- 外屏（紧凑）：底部标签栏；词典卡片在底部，最高占屏幕 50%。阅读器单页。
- 内屏（宽屏）：左侧侧栏；阅读器默认双页，词典卡片浮在另一页上。查单词左右分栏。
- 展开、折叠时保留当前结果和阅读位置（按字符位置重新分页）。

## 体积和技术

- Kotlin + 原生 View，不引入 AndroidX、Compose、网络库；网络用 `HttpURLConnection`，存储用系统 SQLite。
- ePub 解析：ePub 是 zip，用 `java.util.zip` 读 OPF、目录和章节，不引入第三方库；正文交给系统 WebView。
- 代码部分 R8 后预计小于 1 MB，主要体积是词典。6 万词的 SQLite 压缩后估计几 MB，具体以实测为准；需要更小可以再按词频裁剪。
- `minSdk 33`，`targetSdk 36`。本机已有 Android SDK（platforms 34 到 37、build-tools 36.1.0）和 Gradle。

## 首版范围

1. 书库和 ePub 阅读器：导入、目录、书签、主题、字号、四种翻页方式、长按查词。
2. 查单词：快速查词、拍照找生词（OCR、词频粗筛、Jev 判断难度和语境义）。
3. 词典卡片：离线释义、音标、词形还原、朗读、收藏；外屏、内屏两种布局。
4. 外部入口：ColorDict、系统选中菜单、磁贴、桌面快捷方式。
5. 生词本：按时间分组，按来源筛选，导出 CSV。
6. 整句翻译和「问 AI」：配置了 Key 才出现。

不做：PDF、DRM 书、云同步、整页翻译、同步到背单词 App。需要时再加。
