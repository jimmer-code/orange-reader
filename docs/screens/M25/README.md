# M25 分享书摘截图

`excerpt-card*.png` 都是 App 自己的 `excerptCanvas()` 在模拟器 Fold_DS_API36 的 WebView 里生成的原图（1080×1440 PNG），不是设计稿：纸面 `#F7F1DE`、每 3px 一条的 CRT 扫描线、四角 3px 硬框、顶部「书 摘」赭红标签、英文摘录用 Literata、中文译文用系统无衬线、底部书名 · 作者用像素字体。

- `excerpt-card.png`：一段中等长度摘录（7 行英文 + 3 行译文）。
- `excerpt-card-short.png`：短语级摘录，字会自动放大（68px）。
- `excerpt-card-long.png`：一整段长摘录，缩到最小字号后截断，末尾带省略号。
- `excerpt-card-phrase.png`：真实拖选「extreme downtown」这条的成品，用来核对按钮到分享的整条链路。
